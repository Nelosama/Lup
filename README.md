# Lup

## Propósito

Lup es un proyecto de marketplace digital. Busca reunir en una plataforma a quienes ofrecen y a quienes buscan productos o servicios.

## Alcance por definir

El repositorio todavía no documenta qué categorías atenderá, quiénes serán sus usuarios objetivo, cómo funcionarán las publicaciones o las transacciones, ni qué funcionalidades se incluirán. Estos puntos deben confirmarse antes de tratar este README como una especificación detallada.
